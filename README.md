# Guessing Game
-----------------
The program generates a random integer number between 1-100 (inclusive) .
The player will be promtped to enter a guess. After a guess is entered, the program will indicate wthere the guess is either
too low, too  high, or correct. If correct, the game will print a congratualtory message and exit.
